# Quran & Duas — iPhone and Android app

**© 2026 Syed Muhammad Wajih Ali. All rights reserved.** This code may not be copied, modified or distributed without written permission. See [LICENSE](LICENSE).

Shia Quran & Duas app: Quran with Indo-Pak / Madani script, English & Urdu translation and transliteration,
full Quran recitation (Mishary Alafasy), duas & ziyarat (Ashura, Waritha, Ahad, Tawassul, Nudba, Ayat ul Kursi),
Shia Ithna Ashari prayer times with azan notifications, live Qibla compass, Shia calendar, and
home-screen / lock-screen widgets (Next Prayer, Ayah of the Day).

Built with [Capacitor 8](https://capacitorjs.com): one shared app (`src/` → `www/`) plus native code in `native/`.

```
src/        the app itself (HTML/JS + data) — edit here
www/        built app (generated by `npm run build:web`)
native/     iOS + Android code: widgets, widget bridge, background audio, azan sound
scripts/    build-web.mjs (src → www), native-setup.mjs (wires native code into ios/ and android/)
```

## One-time setup on your Mac

You need: **Node.js 22+**, **Xcode 26+** (Mac App Store), **Android Studio** (developer.android.com).
Check Node with `node -v`. If it's missing or older than 22, install it from nodejs.org (LTS).

Open **Terminal** and run:

```bash
git clone https://github.com/cryptopanda94/quran-duas-app.git
cd quran-duas-app
npm install
npm run build:web
npx cap add ios
npx cap add android
npm run native:setup
npm run assets
npx cap sync
npm run ios:plugins
```

`npm run assets` puts the maroon & gold app icon and splash screen into both apps.
`native:setup` will say one thing is still to do by hand: adding the iOS widget. Do the iPhone steps below.

## iPhone

### 1. Open the project
```bash
npx cap open ios
```
Xcode opens.

### 2. Sign the app (free with your Apple ID)
1. In the left sidebar click the blue **App** project, then the **App** target.
2. **Signing & Capabilities** tab → tick **Automatically manage signing** → **Team**: choose your Apple ID
   (Xcode ▸ Settings ▸ Accounts ▸ + if it's not listed).
3. If Xcode says the bundle identifier is taken, change it to something unique, e.g.
   `com.yourname.quranduas`, and use the same prefix in the steps below.

### 3. Add the widget (about 2 minutes)
1. **File ▸ New ▸ Target…** → **Widget Extension** → **Next**.
2. Product Name: **QuranWidget**. **Untick** "Include Live Activity", "Include Control" and
   "Include Configuration App Intent". → **Finish** → if asked to activate the scheme, choose **Activate**.
3. In Terminal run again:
   ```bash
   npm run native:setup
   ```
   (This puts the widget code into the new QuranWidget folder.)

### 4. Turn on App Groups (lets the widgets read prayer times)
Do this for **both** targets — **App** and **QuranWidgetExtension**:
1. Select the target → **Signing & Capabilities** → **+ Capability** → **App Groups**.
2. Click **+** under App Groups and enter exactly: `group.com.cryptopanda94.quranduas`
   (tick it for both targets).

### 5. Run on your iPhone
1. Plug in your iPhone, unlock it, tap **Trust** if asked.
2. On the iPhone: **Settings ▸ Privacy & Security ▸ Developer Mode** → On (restart when asked).
3. In Xcode's top bar pick your iPhone, press **▶ Run**.
4. First time only: on the iPhone go to **Settings ▸ General ▸ VPN & Device Management** → trust your Apple ID.

> With a free Apple ID the app works for 7 days, then press Run again to refresh it.
> With the paid Apple Developer account ($99/yr) it lasts a year and you can publish to the App Store.

### Add the widgets
On your home screen or lock screen: touch and hold → **Edit** → **Add Widget** → search **Quran & Duas**.
Open the app once first (and pick your city in the Prayer tab) so the widgets have data.

## Android

```bash
npx cap open android
```
1. Android Studio opens and syncs (first time can take a few minutes).
2. On your phone: **Settings ▸ About phone** → tap **Build number** 7 times → back to Settings ▸
   **Developer options** → turn on **USB debugging**.
3. Plug in the phone, allow the USB debugging prompt, pick it in Android Studio's device list, press **▶ Run**.

Widgets: long-press the home screen → **Widgets** → **Quran & Duas**.
Azan: in the app's **Prayer** tab tap **Turn on alerts** and allow notifications and "Alarms & reminders".

## After I (or you) change the app

```bash
git pull
npm run sync          # rebuilds www/ and copies it into the iOS + Android projects
```
Then press **Run** again in Xcode / Android Studio. Run `npm run native:setup` again only if files in
`native/` changed.

## If something goes wrong
Copy the **red error text** from Xcode (Report navigator, the last build) or Android Studio (Build tab)
and send it to Claude — it can be fixed from there.
